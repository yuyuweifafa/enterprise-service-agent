## 门禁卡与工牌

### 新入职

入职当日由行政统一发放，含门禁权限（本楼层 + 公共区域）。

### 补办

- 遗失：在服务台报备后由行政注销原卡并制新卡，工本费 30 元从当月工资代扣。补办时限 1 个工作日。
- 损坏：非人为损坏免费更换，交回旧卡即可。
- 临时卡：当日忘带卡的，可在前台登记借用临时卡，当日 19:00 前归还，逾期未还计一次记录，季度内 3 次以上通报部门。

### 权限范围

| 区域 | 默认权限 | 申请方式 |
| --- | --- | --- |
| 本部门楼层 | 有 | — |
| 其他办公楼层 | 无 | 服务台申请，需对方部门负责人同意 |
| 机房 / 配线间 | 无 | 走 IT 特权访问审批 |
| 财务室 / 档案室 | 无 | 服务台申请，需财务或行政负责人同意 |

## 工位

- 新入职工位由行政按部门区域分配。
- 换工位：本部门内调整由部门行政对接人统一提交；跨部门跨楼层调整需两侧部门负责人同意，行政统一在月度工位调整窗口（每月最后一周）执行。
- 储物柜：一人一柜，钥匙押金 50 元，离职归还退还。
- 工位清洁：员工负责台面整理；下班后台面保留纸质文件需上锁，涉密文件按《文件管理规范》处理。

## 访客

访客须由接待人在前台系统提前 1 小时预约，访客到场后前台核验身份证并发放访客卡。访客全程需由接待人陪同，不得单独进入办公区。
